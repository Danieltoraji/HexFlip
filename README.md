# 🪄 HexFlip — 六边形翻转棋

卡通风格的六边形棋盘对战游戏。玩家轮流移动棋子到相邻空格，翻转周围敌方棋子，最终将所有棋子变为己方颜色的一方获胜。

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm start

# 生产构建
npm run build
```

打开 `http://localhost:3000`。

## ✨ 特性

- **六边形棋盘** — 立方体坐标系，半径 2~7 可调
- **卡通视觉风格** — 渐变背景、云朵装饰、玻璃珠棋子、脉冲选中动画
- **2~4 人对战** — 支持自定义颜色、名称
- **PVP / PVE** — 每位玩家可独立设为人类或 AI
- **三档 AI 难度** — 简单（随机）、中等（贪心）、困难（Minimax + α-β 剪枝 + 迭代加深）
- **回放系统** — 步进控制、自动播放、移动列表点击跳转
- **导入/导出** — JSON 格式完整保存棋局（含初始布局）
- **截图** — 一键截取棋盘为 PNG 下载
- **撤销** — 支持回退上一步
- **自动跳过** — 无合法移动时自动跳过回合
- **双获胜条件** — 全棋子同色 / 仅一方可行动

## 🎯 游戏规则

### 棋盘
棋盘为正六边形，由半径 R 决定格子数量。使用**立方体坐标系 (Cube Coordinates)**，每个格子坐标 `(q, r, s)` 满足 `q + r + s = 0`。

### 移动与转化
1. 选择己方棋子
2. 移动到相邻 6 格中的**空白格**
3. 移动后，原格子变空
4. 目标格子周围 6 格中的**敌方棋子全部翻转为己方**

### 获胜条件
- 棋盘上所有非空格子均为同一玩家颜色 → 该玩家获胜
- 场上仅剩一方能够合法移动 → 该玩家获胜

## ⚙️ 配置参数

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 玩家数量 | 2 / 3 / 4 | 2 | 选择后自动分配颜色 |
| 玩家颜色 | 任意 | 红/蓝/绿/橙 | 每位玩家独立设置 |
| AI 开关 | 每玩家独立 | 关闭 | 开启后可选择难度 |
| AI 难度 | 简单/中等/困难 | 简单 | 困难≈Minimax 深度5 |
| 出手顺序 | 顺时针/逆时针 | 顺时针 | — |
| 棋盘半径 | 2 ~ 7 | 4 | 格子数 = 3R² + 3R + 1 |
| 初始占空比 | 30% ~ 90% | 60% | 开局有棋子的格子比例 |

## 🤖 AI 难度说明

| 难度 | 策略 | 特点 |
|------|------|------|
| **简单** | 随机选择 | 快速，适合新手练习 |
| **中等** | 贪心（最大翻转数） | 只看一步，有基本战术意识 |
| **困难** | Minimax + α-β 剪枝 + 迭代加深 | 深度 2~5 自适应，多维评估（棋子数/翻转潜力/中心控制/聚集度），1 秒时间限制 |
